# UNO

Το UNO για παιχνίδι στο σπίτι: το τραπέζι παίζει στην τηλεόραση και κάθε παίκτης βλέπει τις κάρτες του στο κινητό (2–10 παίκτες).
Οι κανόνες είναι στο [RULES.md](RULES.md).

## Πώς παίζεται
1. **Admin** (`/admin`): κωδικός admin → «Νέο παιχνίδι» → βγαίνει τετραψήφιος κωδικός. Διαλέγεις μέχρι πόσους πόντους παίζετε.
2. **Τηλεόραση** (`/tv`): γράφεις τον κωδικό. Δείχνει QR για τους παίκτες.
3. **Παίκτες** (`/`): κωδικός, όνομα, PIN 4 ψηφίων. Με το ίδιο όνομα και PIN ξαναμπαίνουν αν κλείσει το κινητό.
4. **Έναρξη** από το admin. Στο κινητό:
   - Πατάς μια κάρτα για να τη σηκώσεις και ξανά (ή «Παίξε») για να την παίξεις.
   - Πατάς την τράπουλα για να τραβήξεις.
   - Υπάρχουν κουμπιά για ΟΥΝΟ!, Πάσο και «Πιάσε τον!».
5. Admin: Restart, Επόμενος γύρος, Πίσω στην αναμονή, Παράλειψη σειράς, Κλείσιμο.

## Τοπικά

```bash
npm install
```

```bash
npm start
```

Άνοιξε http://localhost:3001/admin (τοπικός κωδικός admin: `admin`). Τεστ: `npm test`.

Ρομπότ για δοκιμές (πατάνε μόνα τους και «Επόμενος γύρος»): `node tools/bot.js --code 1234 --join 3`

Όλες οι κάρτες σε μία σελίδα: http://localhost:3001/cards.html

## Ανέβασμα στο GitHub και στο Render
Όπως στο Ticket to Ride.
- **GitHub:** ανέβασε τους φακέλους `public`, `server`, `test`, `tools` και τα αρχεία `.gitignore`, `package.json`, `package-lock.json`, `README.md`, `RULES.md`, `render.yaml`, `server.js`. **Όχι** τα `node_modules`, `data` και `.claude`.
- **Render:** **New → Blueprint** → διάλεξε το repository → βάλε `ADMIN_PASSWORD` → **Apply**.
